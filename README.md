# TOEIC 650 Lab v5.0.0

繁體中文、手機優先的多益分項練習 PWA（Progressive Web App，漸進式網頁應用程式）。

使用網址：https://noisemore.github.io/toeic-650-lab/

## v5.0.0 學習流程

- 首頁學習教練（Study Coach）：智慧安排與原有隨機模式可切換，各模式的當日順序固定。
- 智慧安排依建立當日時的到期題、首次不同題目暴露的弱點與新題分組抽選。選組目標為複習 30%、弱點 50%、新題 20%；不足時補其他類，整組長度與每日上限可能改變實際題數比例。沒有足夠資料時優先探索新題。
- 題目依 24 個考點分類，每題答後有原創中英短教學、例句、誤判提醒與練習方法；可用其他同考點題目檢驗理解。
- 把握度（Confidence）可標記有把握或猜測。猜對不視為首次確認成功，安排較早複習。
- 跨日複習（Spaced Review）依不同日期的確認排程。錯答／猜測後隔 1 天；連續不同日確認後間隔為 1、3、7、14、30 天。同日重做不推進間隔，當天曾錯／猜會保留待確認狀態。
- 學習報告（Learning Report）分開顯示首次作答與最新表現、跨日確認、連續學習天數和近 7 個學習日。考點少於 3 道不同題目標示樣本不足。舊紀錄缺把握度時依原正誤計入。
- 作答時間從 v5 開始記錄，排除背景頁籤與答後解說，不當作總學習時數。
- 單字回想（Active Recall）使用 400 個完整例句職場詞＋400 個工程詞。到期詞優先，每次最多 10 詞；先回想，再翻面看雙語意思及例句，自評記得／忘記後跨日排程。
- 全部功能本機執行，不需要 AI 金鑰或訂閱。沿用 IndexedDB 與 schema 1 備份，新增 studyPlan 和 wordMemory 欄位，不覆寫既有題目與紀錄。更新預載 284 個資源。

本版為透明的規則式學習安排，未經學習成效實驗與試題校準；不提供正式 TOEIC 分數預測。題庫品質及正式題型完整度仍需持續人工檢驗。

驗證：`node self-check.mjs`、`node learning-check.mjs`。前者涵蓋全庫畫面、舊紀錄與離線資源及新流程事件；後者涵蓋日期、排程、同日去重、猜測、弱點抽選、完整題組與單字排程。

## 閱讀測驗（v4.4.0）

本次新增 100 題：20 題單句填空、5 組段落填空共 20 題、12 組文章閱讀共 60 題（單篇／雙篇／三篇各 4 組）。新題號含 `-XR`；首頁「本次新增 100 題」可直接篩選。所有原 1,024 題完整保留。

文章涵蓋社區公告、差旅規範、活動邀請、軟體支援、課程行程、交貨補件、招聘、會議預約、設備維修、展覽交通、團體餐飲、樣品檢驗。附中文大意、中文解析與具體解題依據；跨文件計算另做獨立驗證。皆為原創練習，非 ETS 官方試題，未經正式試題難度校準。

新增題目自動納入新的每日抽選。若同一天更新，將新題加入既有順序尾端，保留已抽題目、每日單字與標記；既有作答、錯題及收藏不變。

## 今日學習任務

- 首頁可調整每日 1–100 題、1–20 個單字，預設 10 題與 5 個單字；統計頁原有題數設定仍可用。
- 題目從完整 1,172 題抽選，以題組為單位洗牌，保留組內順序；今日上限可以取到部分題組。
- 當天的完整抽選順序存入原本的本機資料。重新整理不重抽，調整數量保留前綴順序，增加數量向後延伸。
- 今日題目進度只算抽中題目中「當天已作答的不同題目」，重做不重複計數。從其他練習完成同一題也會計入；重新開始今日任務會跳過已完成題目。
- 每日單字從含完整雙語例句的 400 個職場重點詞隨機精選。3,000 個一般詞彙與 400 個工程詞彙都保留；基礎延伸詞仍不是每詞都有例句。
- 精選卡片顯示詞義、中英例句與朗讀，可標記今日已學，也會寫入全詞庫的複習紀錄。取消今日標記不抹除先前的全詞庫複習紀錄。
- 按裝置本地日期跨日重新選取。回到首頁或重新開啟可看到新任務；日任務作答途中跨日，在下一題時返回新任務。
- 每日進度、抽選順序包含在原有 JSON 備份中。舊備份沒有日任務欄位時，自動建立，不清除原紀錄。

## 功能

- 七個 Part 分開練習、跨 Part 練習、錯題及收藏。
- 題庫依題號、考點、主題或閱讀題目搜尋，每頁 30 題，避免一次渲染千題。
- 隨機練習以題組為單位抽選，保留組內順序；錯題與收藏仍只抽選符合條件的題目。
- Part 1–4 內建 230 個合成語音（Text-to-Speech, TTS）MP3，總計約 29 MB。支援 0.75×／0.9×／1×、重播與停止，全部納入離線快取。
- Part 1、2 提交前隱藏選項文字；提交後顯示文字、解析與聽力逐字稿。Part 3、4 提供對話／獨白與中文大意。
- Part 3、4、6、7 顯示共用題組，多篇閱讀文件同時顯示；解析指出答案依據。
- IndexedDB（瀏覽器本機資料庫）保留作答、收藏、單字複習及每日目標；支援 JSON 備份匯出／匯入。
- Service Worker（服務工作執行緒）預存 284 個資源，從網路重新取得新版資源後才啟用；只刪除本 App 的舊版快取。

## 自檢

```sh
node self-check.mjs
node --check app.js
node --check data.js
node --check question-bank.js
node --check scenes-expanded.js

```

自檢另含每日抽樣、當日固定、跨日、增減目標、重做去重、續學與單字進度保存；並包含 1,172 題資料與答案範圍、內容去重、170 個題組一致性、原 120 題完整內容雜湊、30 幅情境圖、230 個音檔存在、聽力選項順序、各題作答前後渲染、搜尋／分頁／篩選、隨機題組連續性、舊紀錄及 40 個原詞 ID 相容性、3,000／400 詞庫與離線資源。全部 MP3 另以 FFmpeg 完整解碼檢查。

測試的 DOM、語音與快取使用替身；公開瀏覽器測試另外執行。Android 安裝、飛航模式及實際聲音輸出仍需實機驗證。自動測試不能證明每道題目達到正式試題的測量品質。

## 範圍

不是 ETS／TOEIC 官方產品。Part 1 為AI 生成寫實情境圖，不是考試照片；聽力為合成語音，不是真人錄音。分項題數與篇幅不依正式考試比例組卷，本版沒有完整 200 題計時模擬考，正確率不能換算正式分數。詞數也不是取得 650 分的保證。未包含雲端同步或 AI 家教。

工程情境用於語言學習，不取代原廠手冊、授權訓練或廠區核准程序。
