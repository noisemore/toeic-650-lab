# TOEIC 650 Lab v3.0.0

繁體中文、手機優先的 Part 1–7 原創練習 PWA（漸進式網頁應用程式）。

使用網址：https://noisemore.github.io/toeic-650-lab/

## 七個 Part

| Part | 內容 | 題數 |
| --- | --- | ---: |
| 1 | 圖片描述；6 幅原創向量情境示意圖 | 6 |
| 2 | 應答問題；每題 3 個選項 | 12 |
| 3 | 4 組簡短對話，每組 3 題 | 12 |
| 4 | 4 組簡短獨白，每組 3 題 | 12 |
| 5 | 單句填空，保留 v1 原有題號 | 36 |
| 6 | 3 組段落填空，每組 4 題，包含句子填空 | 12 |
| 7 | 4 組單篇、3 組雙篇、3 組三篇閱讀，每組 3 題 | 30 |
| 合計 | 全部為原創練習題，附繁中解析 | 120 |

另含 3,000 個一般／職場詞彙（400 個原創職場搭配＋2,600 個基礎延伸詞），以及 400 個工程術語與原創雙語例句。原版 40 個詞條的 ID 與複習紀錄相容。

詞庫支援英文、繁中、縮寫與例句搜尋，依主題、層級與已複習狀態交集篩選，每頁 30 個詞條。一般詞庫依基礎與職場情境選詞，並非 ETS 官方 650 分必背字表或分數保證。基礎延伸詞義使用 ECDICT 資料，已作繁中轉換與常見用語修訂；未逐詞新增例句。參考來源、選詞方法與授權見 [SOURCES.md](SOURCES.md) 及 [ECDICT-LICENSE.txt](ECDICT-LICENSE.txt)。

## 功能

- 七個 Part 可分開練習，也可跨 Part 練習。
- Part 1–4 以內建合成語音（Text-to-Speech, TTS）MP3 音檔播放，支援 0.75×／0.9×／1×、重播、停止；作答後可看逐字稿與翻譯。
- Part 1、2 的敘述／回應文字在提交前隱藏；Part 2 只有三個選項。
- Part 3、4、6、7 有共用題組標示；多篇閱讀文件同步顯示。
- 各 Part 共用錯題本、收藏、解析、下一題與最新作答統計。
- IndexedDB（瀏覽器本機資料庫）保存紀錄、單字複習與每日目標；支援 JSON 備份匯出／匯入。
- v1.0.1 的 P5-001 至 P5-036 題號及資料庫名稱保持不變，不需清除舊紀錄。
- Service Worker（服務工作執行緒）快取程式、全部題庫及圖示，更新僅清除本 App 的舊版快取。

## 安裝與更新

Android Chrome 開啟使用網址 → 右上角「⋮」→「新增至主畫面」或「安裝應用程式」。首次保持連網完成載入，再測試飛航模式。

已使用 v1 的使用者請連網重新載入，若仍顯示 36 題，關閉再開啟或再重新載入一次，確認頁首顯示 v3.0.0。不要清除網站資料，以免刪除學習紀錄；可先從統計頁匯出備份。

## 自檢

使用 Node.js 22 以上：

```sh
node self-check.mjs
node --check app.js
node --check data.js
node --check parts.js
node --check scenes.js
node --check sw.js
```

自檢涵蓋 3,400 個詞條各詞庫內去重、40 個舊詞 ID 相容、16 個工程分類、英中與縮寫搜尋、分頁、複習篩選，以及 120 題資料、答案範圍、21 個題組、單雙三篇閱讀、全部題目作答前／後畫面渲染、Part 篩選、舊版紀錄相容性、語音停止取消，以及 39 個離線資源與版本快取清理。測試以 DOM／語音／快取替身執行，不代表 Android 聽覺輸出或飛航模式實機測試。

## 範圍

此專案不是 ETS／TOEIC 官方產品。Part 1 使用原創插畫示意而非考試照片；聽力內建 26 個合成語音 MP3 音檔（約 2.2 MB），不是真人錄音；離線快取包含全部音檔。單字朗讀仍使用裝置語音引擎。

本版提供七個 Part 的分項練習，不是依正式題數比例組成的 200 題計時模擬考，也不能由正確率換算正式 TOEIC 分數。600 題擴充、真人聽力、雲端同步與 AI 家教尚未包含。

## 原始檔

- `index.html`、`styles.css`：入口與手機版畫面。
- `app.js`：練習、語音、導覽與紀錄。
- `data.js`：Part 5、單字及工程英文；匯入七個 Part 的完整題庫。
- `parts.js`：Part 1–4、6、7 原創題庫。
- `scenes.js`：Part 1 原創向量情境圖。
- `manifest.webmanifest`、`sw.js`、`icons/`：安裝與離線資源。
- `audio-*.mp3`：Part 1–4 的內建合成語音音檔（對話依說話者切換聲音）。
- `vocabulary.js`：3,000 個一般／職場詞彙及 400 個工程術語。
- `lexicon.js`：詞彙搜尋、篩選、分頁及來源連結。
- `SOURCES.md`、`ECDICT-LICENSE.txt`：來源、方法與授權。
- `self-check.mjs`：資料、渲染、相容性及離線自檢。
